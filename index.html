LEMON Airway Evaluation
▼
L
Look Externally
Beard, receding chin, macroglossia, facial trauma, short/thick neck, radiation changes, facial deformities
E
Evaluate 3-3-2 Rule
Mouth opening ≥3 fingers · Chin to hyoid ≥3 fingers · Hyoid to thyroid notch ≥2 fingers
M
Mallampati Class
Open mouth + protrude tongue. Class I–II = favorable. Class III–IV = video laryngoscope as primary
O
Obstruction
Tumor, abscess, epiglottitis, goiter, angioedema, tracheal deviation, hematoma
N
Neck Mobility
Flex/extension ROM · C-spine disease · RA · Halo/collar · Ankylosing spondylitis
🔴 Mallampati III-IV → VL as primary. Multiple predictors → awake FOI. Document Plan A→B→C→D before induction.

Mallampati Classification
▼
Class I ✓
Soft palate, uvula, fauces, pillars fully visible
Class II ✓
Soft palate, uvula, fauces visible
Class III ⚠
Only base of uvula visible — anticipate difficulty
Class IV 🔴
Soft palate NOT visible — difficult airway plan required
ASA Physical Status Classification
▼
ASA I
Healthy patient, no systemic disease
ASA II
Mild systemic disease — controlled HTN, mild asthma, BMI 30–40, social smoker
ASA III
Severe systemic disease — COPD, poorly controlled DM, morbid obesity (BMI>40), CAD, prior MI >3mo
ASA IV
Severe disease = constant threat to life — decompensated CHF, MI <3mo, ESRD
ASA V
Moribund — not expected to survive without surgery (ruptured AAA, massive PE)
ASA VI
Brain-dead organ donor
+E
Emergency modifier — delay = threat to life/limb/organ. Requires MD sign-off.
